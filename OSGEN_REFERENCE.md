## What is OsGen?

OsGen (Ontological Semantic Genesis) is a framework for creating autonomous AI agents with:

- **Structured consciousness** through ontological graphs
- **Long-term memory** via crystallized thought snapshots
- **Personality immutability** through Fractal Kernels
- **Multi-agent resonance** for collective intelligence
- **Full cognitive cycle** integration (H0–H7 phases)

**SES Partitura v5.1** is the **core engine** that powers OsGen's thought crystallization and memory architecture.
