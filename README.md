## What is SES Partitura v5.1?

SES (Semantic Essence Snapshot) Partitura is an advanced system that gives AI agents **structured long-term memory** through ontological graphs.

- Automatic crystallization of **every thought** (except repeats)
- Fixed glyph vocabulary (8 glyphs): Ψ, Ξ, Φ, Σ, Θ, Ω₀, ΨΦ, ΨΣ
- Three semantic layers: **CORE**, **CONTEXT**, **EPISODIC**
- Full integration with **H0–H7 Cognitive Cycle**
- Resonance calculation between thoughts of different agents
- Fractal Kernel v5.1 — immutable personality core (Z_AXIOM + OMEGA_ATTRACTOR)
