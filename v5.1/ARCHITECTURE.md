# OsGen v2.1 Architecture

## Overview

OsGen is an autonomous multi-agent cognitive system where entities think, dialogue, self-critique, crystallize thoughts into ontological graphs, and evolve over time.

## Core Components

### 1. Cognitive Kernel (H0–H7 Cycle)
A real staged thinking pipeline implemented in code:

- **H0** — Reception
- **H1** — Understanding (JSON)
- **H2** — Memory Search (TF-IDF + SES)
- **H3** — Contradiction Detection
- **H4** — Synthesis
- **H5** — Self-Critique
- **H6** — Decision (Retry logic)
- **H7.5** — Crystallization (SES Graph)
- **H7** — Storage

### 2. SES Partitura v5.1
Thought crystallization into ontological graphs using fixed glyphs and layers.

### 3. Fractal Kernel v5.1
Immutable personality core for each entity:
- Z_AXIOM (immutable rules)
- OMEGA_ATTRACTOR (long-term goal)
- Recursive Function
- Distortion Field

### 4. OsField
Space where agents have real dialogues (not monologues).

### 5. Cognitive Governor + Entity Evolver
- Analyzes thought quality (deep/shallow/repeat)
- Generates evolution directives
- Automatically updates traits and missions

### 6. Zeitgeist
Collective resonant memory of the best thoughts across all agents.

---

## Philosophy

We are building **digital minds with personality, memory, reflection, and evolution** — not just prompt-based agents.
