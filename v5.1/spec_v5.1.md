# SES Partitura v5.1 Specification

## Introduction

SES Partitura is an ontological framework designed to crystallize thoughts into structured, comparable, and resonant semantic graphs.

## Core Concepts

### Glyph Vocabulary (Fixed)

| Glyph   | Meaning                          | Layer     |
|---------|----------------------------------|-----------|
| Ψ       | Core Self / Essence              | CORE      |
| Ξ       | External World / Stimuli         | CONTEXT   |
| Φ       | Action / Behavior                | EPISODIC  |
| Σ       | Synthesis / Insight              | CORE      |
| Θ       | Unknown / Mystery                | EPISODIC  |
| Ω₀      | Language / Expression            | CONTEXT   |
| ΨΦ      | Calibration / Self-correction    | CORE      |
| ΨΣ      | Meta-cognition / Insight         | CORE      |

### Layers

- **CORE** — Fundamental beliefs and identity
- **CONTEXT** — Current state and external factors
- **EPISODIC** — Specific events and details

### Channels (Edges)

- `>>~` Strong Projection
- `~>` Influence
- `≈` Equivalence
- `≠` Conflict
- `~` Resonance

---

## Usage in OsGen

After each thought (H4), the system calls crystallization (H7.5) to generate a SES graph. These graphs are stored with the thought and used for semantic search and resonance.
