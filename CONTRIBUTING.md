# Contributing to SES Partitura

Thank you for your interest in contributing!

## How to Contribute

1. **Fork** the repository
2. Create a new branch (`git checkout -b feature/amazing-idea`)
3. Make your changes
4. Test your changes locally
5. Submit a **Pull Request**

## Areas We Need Help With

- Improving SES graph quality and glyph consistency
- Better resonance algorithms
- Documentation and examples
- Testing with different local models
- Visualization improvements

## Code Style

- Keep code clean and well-commented
- Prefer clarity over cleverness
- All new features should work with small models (4B–7B)

---

We welcome ideas, bug reports, and improvements!
